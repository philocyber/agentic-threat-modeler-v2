# Changelog

## Unreleased

Argus is an experimental local proof of concept. This repository has not published a versioned release yet.

The current preview includes a local project workspace, a separate analysis worker, STRIDE and PASTA-inspired analysis, attack trees, bounded Red/Blue review, DREAD scoring, source references, reviewer decisions, optional knowledge retrieval, and report exports. See the [README](README.md) for setup and the [current-state guide](docs/architecture/current-state.md) for implemented limits.
